#BolleyVall_Placar - Placar de Vôlei

PWA simples para marcar pontos de partidas de vôlei amador, pensada para ser usada com o celular deitado (fisicamente na horizontal).

## Funcionalidades
- Toque no campo do time para somar 1 ponto; use as setinhas para ajustar manualmente
- Cronômetro geral, iniciado automaticamente no primeiro ponto ou ao tocar nele
- Nomes dos times editáveis (padrão: Time 1 / Time 2)
- Cor de cada time personalizável
- Tela sempre ativa durante o jogo (Wake Lock)
- Progresso salvo automaticamente no aparelho
